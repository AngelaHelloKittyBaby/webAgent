# 何时使用
设计/修改数据库表，或给已有系统加表、加索引时。

# 步骤
1. 先画实体关系：明确每张表的主键、外键、一对多/多对多，别边写边加列
2. 字段规范：主键 `id`（自增或 UUID）；时间用 `created_at`/`updated_at`；金额/计数用合适类型（勿用浮点存钱）
3. 约束内建：`NOT NULL` + 默认值写在表里，别靠应用层兜底；唯一约束直接建 `UNIQUE`
4. 索引按查询走：WHERE/JOIN/ORDER BY 的列加索引；组合索引把最左前缀放前面；别给低频列乱加索引
5. 状态字段存短期值：`status` 用 tinyint/枚举 + 注释，外部展示名放前端映射
6. 变更用迁移（migration）文件，别手工 ALTER；迁移要可回滚

# 注意
- 多对多建中间表（如 `user_roles`），别在单表里塞逗号分隔的 id
- 软删除看需求，别默认加 `deleted_at`（复杂化所有查询）
- 大文本/JSON 单独评估：必要时拆表或放对象存储
